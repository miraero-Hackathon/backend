## 참고 사항

- 기준 결과와 변경 후 결과는 같은 시나리오와 유사한 인프라 조건에서 측정합니다.
- Load workload는 최대 안정 부하가 아니라 개선 전후 비교를 위해 정의한 기준 부하입니다.
- 중요한 실험은 동일 조건에서 3회 이상 실행하고 주요 지표별 중앙값을 대표값으로 사용합니다.
- 로그인처럼 `setup()`에서 실행되는 요청이 있으면 API 태그가 붙은 지표를 기록합니다.
- CloudWatch 지표는 실제 부하 발생 구간과 동일한 조회 구간에서 평균과 최대값을 기록합니다.
- 비밀번호, Access Token, API Key 등의 민감정보를 기록하지 않습니다.
- 원본 JSON이나 CSV처럼 용량이 큰 결과 파일은 Git에 커밋하지 않습니다.
